# StudyLoom

Static landing page (HTML, CSS, JS — no build step).

## Publish on GitHub Pages
1. Create a new repository on GitHub (e.g. `studyloom`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the root of the repo.
3. Go to **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://<your-username>.github.io/studyloom/`.

## Note
The join form in `script.js` only shows a message. Connect it to a form service before collecting real emails.
